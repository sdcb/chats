# Chats 1.17.1

Release date: 2026-11-22

This page records the security fixes and improvements delivered in Chats 1.17.1. This is a security patch release, and all users are encouraged to upgrade.

## .NET Brotli vulnerability fix (CVE-2026-111497)

- The .NET Brotli decoder contains an out-of-bounds write vulnerability. Chats decompresses request bodies with `Content-Encoding: br` during request tracing, so it is affected.
- This release is rebuilt on the latest .NET 10 runtime (10.0.15). Docker images (based on `mcr.microsoft.com/dotnet/aspnet:10.0` and Nano Server images) and all self-contained binary packages include the fix.
- If you use the framework-dependent package (`chats.zip`), upgrade the ASP.NET Core runtime on your server to 10.0.14 or later.

## MCP permission hardening

- Viewing the assigned-user details of an MCP server now requires an admin or the MCP owner. This fixes an issue where assigned users could read other users' custom headers, which may contain personal credentials (#148).
- MCP detail and management-list APIs no longer return the server URL or headers to users who are neither the owner nor an admin.
- The read-only MCP modal in the frontend now hides the Server URL and Headers fields.
- Adds unit tests for `McpController` permissions.

## Image processing

- File image-info detection now supports the WebP format.
- Removes the SixLabors.ImageSharp dependency; image header parsing now uses Sdcb.SimdCodecs 2.0.0.
- The code-interpreter image's NuGet precache switches from `SixLabors.ImageSharp` to `Sdcb.SimdCodecs`.
- Adds `FileImageInfoService` unit tests covering PNG, JPEG, WebP (lossy, lossless, and extended), GIF, BMP, and invalid input.
