# Chats 1.17.1

发布日期：2026-11-22

本页记录 Chats 1.17.1 已交付的安全修复和改进。本版本为安全补丁版本，建议所有用户升级。

## .NET Brotli 漏洞修复（CVE-2026-111497）

- .NET 的 Brotli 解码器存在越界写漏洞，Chats 在请求追踪中会解压 `Content-Encoding: br` 的请求体，因此受到影响。
- 本版本基于最新的 .NET 10 运行时（10.0.15）重新构建，Docker 镜像（`mcr.microsoft.com/dotnet/aspnet:10.0` 及 Nano Server 基础镜像）和各平台 self-contained 二进制包均已包含修复。
- 使用框架依赖版（`chats.zip`）的用户，请将服务器上的 ASP.NET Core 运行时升级到 10.0.14 或更高版本。

## MCP 权限加固

- 查看 MCP 服务器的已分配用户详情现在要求管理员或该 MCP 的所有者权限，修复被分配用户可以读取其他用户自定义 Headers（可能包含个人凭据）的问题（#148）。
- MCP 详情和管理列表接口不再向非所有者、非管理员返回服务器 URL 和 Headers。
- 前端只读 MCP 弹窗同步隐藏 Server URL 和 Headers 字段。
- 新增 `McpController` 权限相关单元测试。

## 图像处理

- 文件图像信息识别新增 WebP 格式支持。
- 移除 SixLabors.ImageSharp 依赖，图像头解析改用 Sdcb.SimdCodecs 2.0.0。
- 代码解释器镜像的 NuGet 预缓存同步由 `SixLabors.ImageSharp` 更换为 `Sdcb.SimdCodecs`。
- 补充 `FileImageInfoService` 单元测试，覆盖 PNG、JPEG、WebP（有损、无损、扩展格式）、GIF、BMP 及异常输入。
