# Chats 1.17.0

本页用于记录 Chats 1.17.0 已交付的功能、改进和修复，内容将在版本开发过程中持续补充。

## 响应速度统计优化

- 前端 Token 速度改为仅统计首个 Token（TTFT）之后的生成阶段，计算时从总耗时中扣除 TTFT，避免首 Token 等待时间拉低后续生成速度。
- 保持现有输出 Token 统计口径；当扣除 TTFT 后没有有效生成耗时时，速度显示为 `-`，避免出现无穷大或负数。

## 图像生成背景模式

- 图像生成模型的 ChatConfig、配置快照、聊天配置接口和预设配置支持背景模式：默认（`NULL`，请求中 omit）、`auto`、`opaque` 和 `transparent`。
- 配置界面默认显示“默认”，切换为自定义后可选择 `auto`、`opaque` 或 `transparent`；透明背景仅允许使用 `png` 或 `webp`，点击选择不兼容的 JPEG 格式时通过 Toast 提示。
- 新增 SQL Server 和 SQLite 数据迁移，并将背景模式纳入配置快照和哈希计算；默认状态保持上游 API 的默认行为。

## 模型上下文提示词

- 图片生成模型直接使用用户原始文本作为提示词，不再发送 `UserContextTemplate` 包装内容。
- 文本和 Agent 模型的上下文模板保留当前时间及必要的运行时上下文，不再额外注入模型名称。

## 聊天分支分页稳定性

- 修复实时 SSE 最终消息缺少 `siblingIds` 的问题。重新生成或生成失败后，前端不再因为无法定位当前分支而显示 `0/N`，也不会再请求 `undefined/subtree`。
- 后端在发送用户消息和助手最终消息时，根据当前聊天的 turn 元数据补齐 sibling 分支列表，使实时响应与刷新后的消息查询保持一致。

## 用户管理与修改密码

- 将新增用户、编辑用户和修改密码拆分为三个独立表单，避免隐藏的密码字段残留导致用户编辑无法保存且没有错误提示。
- 修复修改密码表单校验状态不同步时点击保存不发起请求的问题。
- 修改密码弹窗显示目标用户真正的登录账号（只读），并补充 `autocomplete` 信息，帮助浏览器密码管理器将新密码关联到正确用户。
- 新密码和确认密码输入框支持点击眼睛切换明文显示。

## OpenAI 图像接口与模型配置稳定性

- 修复 Model Key 或模型级 URL 已包含 `/v1` 时，图像生成/编辑请求重复拼接路径，导致请求错误发送到 `/v1/v1/images/...` 的问题。
- 图像生成和编辑链路现在会智能识别已有的 `/v1`，同时继续保留模型级 Custom URL 的优先级。
- 修复 `ChatConfig.Model` 可为空后执行链路中的空引用风险：模型请求在入口统一校验，缺少模型配置时返回明确的内部配置错误。
- 清理后端 web、模型服务和测试项目中的 nullable 编译警告，并增加空模型回归测试。
