# Maintenance scripts

This project contains repository maintenance assets and is not part of the application runtime.

- `db-migration/`: versioned SQL Server and SQLite database migrations.
- `restore/`: local development database restore scripts.
- `tools/`: scaffolding and repository maintenance utilities.
- `img/`: images used by maintenance tooling.

Before running a script, review its target database, expected source version, and provider-specific variant.
